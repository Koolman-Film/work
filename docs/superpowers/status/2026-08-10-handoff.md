## 3. THE OPEN QUESTION — EMP-A's ฿27,450 (unresolved)

Production payroll row, 2026-08-03:
```
base ฿13,500 · SSO −฿675 · leave deduction −฿27,450 · net −฿14,625
```

Arithmetic verified exactly: `13,500 / 30 = ฿450/day`, `27,450 / 450 = 61.0 days`.

**Root cause of the SIZE:** the payroll sweep (`payroll/run.ts` ~line 190) has an upper
date bound only —
```ts
if (c.swept) continue;
if (c.startDate.getTime() > end.getTime()) continue;   // ← no LOWER bound
```
and `computeLiveLeaveCharges` has no date filter at all. So every approved over-quota
leave request never swept into a published payroll lands in whichever month is
calculated next.

**STILL NOT DIAGNOSED.** Two very different possibilities:
- **ONE request of ~61 days** → mistyped end date. Fix that request. The waiver feature
  is then unnecessary for her.
- **MANY requests across months** → real backlog, and it becomes a policy decision.

**How to resolve it: open `https://work.kool-man.com/admin/tools/leave-backlog`.**
That page was built for exactly this and is already live. It flags the
single-large-request case inline and shows anyone else carrying a balance (EMP-A was only
visible because her salary was small enough to go negative).

The customer's own complaint *"วันลากิจ แสดงจำนวนวันคงเหลือมากกว่า 1 ชม แต่ทำไมถึงโดนหักเงิน"*

## 7. Environment gotchas hit this session

- **Test DB container stops between sessions.** `supabase_db_koolman_hr` on port 54422.
  When every integration file fails to LOAD (not fail assertions), that is the cause:
  `docker start supabase_db_koolman_hr`, wait for healthy, then `npm run db:test:deploy`.
- **Merging a schema branch leaves a stale Prisma client.** The generated client is a
  build artifact not in git. After merging anything touching `schema.prisma`, run
  `npx prisma generate` or typecheck fails on the new columns. CI/Vercel regenerate on
  build, so this is local-only.
- **`vercel inspect` on the BRANCH ALIAS lies during a deploy.** It reports the PREVIOUS
  build as Ready. Always resolve the deployment's own immutable URL
  (`work-<hash>-vivatchais-projects.vercel.app`) before watching a deploy.
- **Push is via HTTPS + gh credential helper** (SSH is denied):
  `git -c credential.helper='!gh auth git-credential' push https://github.com/Koolman-Film/work.git main:main`
- Production domain is `work.kool-man.com` (NOT `hr.koolman.co` — that only appears in
  v2 planning docs and "e.g." comments).
